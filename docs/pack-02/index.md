# Пак 02: Multi-stage Docker, CI/CD SSH Deploy и Runbook отката

!!! warning "Статус: В процессе / Активный спринт (18–31 августа 2026)"
    Текущий рабочий спринт. Фокус на переходе к автоматическому деплою без ручных правок на сервере, детерминированных сборках Docker и составлении регламентов отката при инцидентах.

---

## 🎯 Ключевые цели спринта

1. **Multi-stage сборка Docker-образов**
    * Минимизация размера финального контейнера (Alpine / Distroless).
    * Безопасность: запуск под непривилегированным пользователем (`USER appuser`).
    * Очистка сборочных зависимостей, компиляторов и кэша из production-образа.

2. **Автоматический CD через SSH по коммитам**
    * Деплой конкретного SHA коммита: `deploy_$CI_COMMIT_SHORT_SHA`.
    * Категорический отказ от `latest` в production-окружениях.
    * Передача секретов и переменных окружения через GitLab CI Variables без сохранения в Git.

3. **Runbook отката (Rollback Procedure)**
    * Формализованный регламент действий при сбое свежего релиза.
    * Мгновенный откат сервиса на заведомо рабочий SHA за время $\le 60$ секунд.
    * Логирование инцидента и фиксация состояния.

4. **Nginx Reverse Proxy и балансировка**
    * Настройка upstream proxying на бэкенд-контейнеры.
    * Корректная проброска заголовков: `Host`, `X-Real-IP`, `X-Forwarded-For`, `X-Forwarded-Proto`.
    * Безопасная обработка таймаутов и ошибок 502/504.

5. **Конвенция Pull Request и гигиена Git**
    * Оформление PR с описанием blast radius и шагов проверки.
    * Атомарные коммиты и понятная история изменений.
