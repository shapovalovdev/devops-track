# Материалы паков

Учебные материалы к двухнедельным пакам. Собираются в статический сайт.

**Сайт:** https://shapovalovdev.github.io/devops-track/

---

## Как это собирается

```
docs/            содержимое сайта (Markdown + одна standalone-страница)
mkdocs.yml       конфигурация MkDocs Material
overrides/       правка шаблона темы
requirements.txt зафиксированные версии
test_search.py   проверка, что поиск действительно работает по-русски
```

Локально:

```
pip install -r requirements.txt
mkdocs build --strict
python3 test_search.py
```

Каждый push в `main` запускает [сборку](.github/workflows/pages.yml): установка из
`requirements.txt` → `mkdocs build --strict` → проверка поиска → деплой на Pages.
Сборка идёт на чистом раннере, а не на чьей-то машине, — поэтому то, что
опубликовано, зависит только от того, что лежит в репозитории.

## Одна неочевидная вещь

Поиск по русскому тексту на этом стеке ломается **молча**. Индекс собирается,
строка поиска на месте, запрос кириллицей возвращает ноль результатов — а
латиницей работает. Причина и измерения — в комментарии в `mkdocs.yml`.
Не добавляйте `pipeline: [..., stemmer]`, не прочитав его.

`test_search.py` существует именно для этого: он гоняет настоящий браузер по
собранному сайту и роняет сборку, если русский запрос ничего не нашёл.

## Правки

Этот репозиторий собирается автоматически и перезаписывается целиком при
каждой публикации. Править содержимое здесь бесполезно — правки исчезнут.
