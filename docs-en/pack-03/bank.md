# Question Bank — Pack 03

Rapid-fire screening questions for verbal articulation drills:

1. `ss -tulpn` — explain every flag within 5 seconds.
2. `lsof -i :80` — what does the kernel output?
3. `ip route get 8.8.8.8` — what routing determination does the kernel report?
4. Why does Prometheus specify a configurable `scrape_interval`?
5. What is the mathematical and practical difference between `rate(http_requests_total[5m])` and `increase(http_requests_total[5m])`?
6. What is the synthetic `up` metric, and what values does it evaluate to?
7. Why does using mutable `:latest` break automated release rollbacks?
